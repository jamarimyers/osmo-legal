# Expected image files

Filenames are what `integration/index.html` references, so a new file
only needs to land here under the exact name below.

| Filename | Section it illustrates |
|---|---|
| `01-connect-entry.png` | Connect entry point |
| `02-whoop-authorization.jpg` | WHOOP authorization consent screen |
| `03-authorization-confirmed.jpg` | Authorization confirmed |
| `04-connected-state.jpg` | Connected state in app |
| `05-athlete-data.png` | Athlete view of their own data |
| `06-data-sharing.png` | Per-coach data sharing controls |
| `07-coach-roster.png` | Coach roster, derived labels only |
| `08-disconnect-flow.jpg` | Disconnect flow |
| `09-account-deletion.jpg` | Account deletion |
| `10-legal-access.jpg` | In-app access to legal documents |

All 10 slots are filled.

If a new file's extension does not match the table (e.g. you have a
`.jpg` where `.png` is listed), either convert it or update that one
`<img src>` in `integration/index.html` to match.
